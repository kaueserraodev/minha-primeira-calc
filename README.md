# 🧮 Minha Primeira Calculadora

Uma calculadora web desenvolvida com HTML5, CSS3 e JavaScript, criada com o objetivo de praticar conceitos fundamentais de desenvolvimento web e lógica de programação.

## 📌 Sobre o projeto

A ideia do projeto foi desenvolver uma calculadora funcional, com uma interface moderna e simples de utilizar.

Além das operações matemáticas básicas, o projeto possui um sistema de histórico, permitindo que o usuário visualize as contas realizadas durante a utilização da calculadora.

## 🚀 Funcionalidades

- ➕ Adição
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- ⌫ Botão para apagar números
- 🧹 Botão para limpar a calculadora
- 📋 Histórico das operações realizadas
- 🗑️ Botão para limpar o histórico
- 📱 Interface adaptável para diferentes tamanhos de tela

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ⚙️ Como funciona

O usuário pode utilizar os botões da calculadora para inserir números e operadores matemáticos.

Ao clicar no botão `=`, o JavaScript realiza o cálculo da expressão e apresenta o resultado no visor.

Cada operação realizada também é adicionada ao histórico, permitindo que o usuário consulte as contas anteriores.

O botão **Limpar histórico** remove todas as operações armazenadas no histórico.
